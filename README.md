# Soundborn

WIP Unity turn-based RPG for iOS. Musical genre characters fight The Silence through tower battles, recruiting new allies, and equipment.

## Status

Prototype with core functions

## Requirements

- Unity `6000.3 LTS`

## Run

1. Open the project in Unity 6.3.
2. Open `Assets/Scenes/HomeScene.unity`.
3. Press Play.

## Notes

All data is configured through C# scripts in `Assets/Scripts`, `Assets/Configs`, `Assets/Items`, and `Assets/Sprites`.
